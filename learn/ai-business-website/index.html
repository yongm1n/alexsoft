내 가게 홈페이지, 말로 만들어 공개하기.

처음 홈페이지를 만드는 사장님을 위한 자료입니다. ChatGPT 앱에 말하듯 부탁해 홍보용 홈페이지를 만들고, 내 GitHub 계정의 공개 저장소에서 GitHub Pages로 공개하고, 고치고 싶을 때 다시 말로 고치는 과정을 63장 슬라이드와 한 편의 글로 정리했습니다. 기본 과정 30장이 공개 주소까지, 선택 과정 33장이 수정·도메인·검색 등록입니다.

따라 해보는 슬라이드 63장

기본 과정 1–30장은 내 정보 준비, ChatGPT 앱, 가게 내용 만들기, GitHub 공개 저장소, GitHub Pages 공개 주소까지 한 장에 한 걸음씩 갑니다. 선택 과정 31–63장은 말로 수정하기, 내 이름 주소(도메인) 연결, SEO·GEO와 Google·네이버 검색 등록입니다. ChatGPT에 붙여 넣을 요청문 15개가 들어 있고, 대괄호 안을 내 가게 정보로 바꾼 뒤 복사 버튼으로 옮기면 됩니다.
