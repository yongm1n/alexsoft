01 / NATIONAL E-INVOICING

BIR · KOICA · 2018–2022

필리핀 국세청
Electronic Invoicing and
Sales Reporting System

EIS / OPERATIONS
DOCUMENT STANDARDSECURE EXCHANGE
CONTEXT

국가 전자송장 의무화

필리핀 국세청의 전자송장 의무화 기반을 만들기 위해 KOICA 무상원조로 2018–2022년 구축한 국가 단위 시스템입니다.

ROLE

개발 PL

개발 아키텍처, e-invoice 문서 표준, 문서 및 교환체계 보안 표준을 설계하고 개발을 주도했습니다.

CONSTRAINTS

모두가 따라야 하는 규격

국가 규모 처리, 다수 사업자가 같은 의미로 해석해야 하는 문서와 전송 규격, 구축 뒤 정부 조직으로의 운영 이관을 함께 고려했습니다.

RESULT

2022년 7월 가동

대형납세자 100개사를 대상으로 가동했으며 현재 eis.bir.gov.ph에서 운영 중입니다.

실적 구분

2018–2022 1차 구축알렉스소프트의 경험

2025–2026 2차 사후지원별도 수행사가 진행한 사업으로 알렉스소프트 실적이 아님

같은 문제를 가진 곳에

의무화 대응은 API 하나를 붙이는 작업이 아닙니다. 문서 의미, 검증과 보안, 실패 처리, 감사 추적과 운영 이관이 같은 구조에서 이어져야 여러 기업과 시스템이 함께 움직일 수 있습니다.

CONTEXT

국내 대형 ERP 기업의 의료 사업 진입

새로운 의료 사업에서 의원급 의료기관이 실제로 사용할 수 있는 클라우드 EMR 제품을 만들었습니다.

CONSTRAINTS

의료법·청구·개인정보·EMR 인증

기능 요구만이 아니라 법제, 청구 흐름, 민감정보 처리와 인증 항목이 제품 구조와 운영에 직접 연결됐습니다.

ROLE

개발 리더 → 최근 3년 개발·기획설계 총괄

2022년부터 2026년까지 개발 리더로 시작해 최근 3년은 개발과 기획설계를 총괄했습니다. 병원정보시스템 배경을 바탕으로 제품과 현장 사이의 결정을 이어갔습니다.

RESULT

인증을 통과한 클라우드 제품

EMR 인증을 받은 의원급 EMR 중 최초의 클라우드 제품으로 완성했습니다.
